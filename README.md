## Selected systems

| System | What I built | Signal path |
| :-- | :-- | :-- |
| [**mocapX1**](https://github.com/ManoharPaturi/manu_mocap) | Offline-first markerless motion capture with a FastAPI + React/Three.js interface | pose → stereo DLT → filtering → kinematics → C3D/BVH |
| [**Self-play RL**](https://github.com/ManoharPaturi/TIC-TAC-TOE-Player-By-DOUBLE-DQN-MODEL) | A Tic-Tac-Toe agent trained from scratch with Double/Dueling DQN, NoisyNets, and prioritized replay | state → value/advantage streams → replay → policy |
| [**EEG denoising**](https://github.com/ManoharPaturi/D9_MFC4_SVD-BASED-NOISE-REDUCTION-IN-EEG-SIGNALS-) | SVD-based removal of EOG artifacts from real Emotiv EPOC X recordings | 14-channel EEG → low-rank subspace → cleaner signal |
| [**projX**](https://github.com/ManoharPaturi/projX) | A fully offline mobile workflow for evaluating OMR sheets | camera → OpenCV → answer-key matching → report |
